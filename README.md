# 🏢 SKT-Orken Official Site

Профессиональный корпоративный сайт, разработанный на фреймворке **Flask**. Проект включает в себя адаптивную верстку, статические ресурсы и систему маршрутизации.

## 🚀 Инструкция по запуску

### 1. Подготовка окружения
Создайте и активируйте виртуальное окружение:
\`\`\`bash
python3 -m venv venv
source venv/bin/activate
\`\`\`

### 2. Установка зависимостей
Установите необходимые пакеты (Flask, Werkzeug и др.):
\`\`\`bash
pip install -r requirements.txt
\`\`\`

### 3. Запуск сервера
Запустите приложение командой:
\`\`\`bash
python3 app.py
\`\`\`

> **Примечание:** На macOS порт 5000 может быть занят системой (AirPlay). Данный проект настроен на работу через порт **5009**.

Локальный адрес сайта: **[http://127.0.0.1:5009](http://127.0.0.1:5009)**

## 📂 Структура проекта
* \`app.py\` — Основной файл сервера Flask.
* \`templates/\` — HTML-шаблоны (основная страница \`index.html\`).
* \`static/css/\` — Стили оформления (дизайн).
* \`static/images/\` — Логотипы и фоновые изображения.
* \`static/js/\` — Интерактивные скрипты.

## 🛠 Стек технологий
* **Backend:** Python 3.12+ / Flask
* **Frontend:** HTML5, CSS3, JavaScript
* **Environment:** Virtualenv
